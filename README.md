# Diwali Host Spin Wheel (React)

A responsive React + Vite app inspired by the Diwali wheel UI.

## Features
- Add up to 15 names (starts with 14 sample names).
- Remove names from the list.
- Spin animation and randomly selected host.
- Reset the starter list.
- Keyboard focus styling and reduced-motion support.

## Run locally
1. Install Node.js (LTS) if it is not installed.
2. Extract this folder.
3. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite, usually `http://localhost:5173`.

To create a production build, run `npm run build`.

The `public/diwali-reference.png` file is the visual reference image; the app UI is built with React and CSS, not a flattened screenshot.
